# Security Policy

## Supported versions

AEGISX is currently pre-release software. Security fixes are applied to the latest revision of the `main` branch until a stable release policy is published.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities through a public issue. Use the repository's **Security** tab to submit a private vulnerability report through GitHub Security Advisories.

Include:

- The affected revision or release.
- A concise description and security impact.
- Reproduction steps using a safe, isolated environment.
- Relevant logs or evidence with credentials and client data removed.
- A suggested remediation, when available.

Do not include live target data, access tokens, credentials, or personally identifiable information.

## Authorized use

AEGISX is intended only for systems that the operator owns or is explicitly authorized to assess. Reports concerning misuse of the framework should include enough non-sensitive context for maintainers to evaluate the concern.
